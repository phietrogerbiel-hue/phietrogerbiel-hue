## ⭐ Projeto em destaque: termsgen

Sistema web que gera termos de responsabilidade de equipamentos em PDF a partir de modelos Word, envia cada termo para assinatura eletrônica no Clicksign e acompanha quem já assinou. É a versão pública, com dados fictícios, de um sistema interno que desenvolvi para a equipe de TI.

| Formulário | Termo gerado |
| --- | --- |
| <img src="https://raw.githubusercontent.com/phietrogerbiel-hue/termsgen/main/docs/formulario.png" width="400" alt="Formulário do termsgen no tema escuro" /> | <img src="https://raw.githubusercontent.com/phietrogerbiel-hue/termsgen/main/docs/termo-exemplo.png" width="400" alt="Primeira página de um termo gerado com dados fictícios" /> |

- Validação no navegador e no servidor com o mesmo arquivo de regras
- Modelos Word preenchidos com docxtemplater e convertidos em PDF pelo LibreOffice
- Integração com a API REST v3 do Clicksign e painel de acompanhamento com SQLite
- Login com hash `scrypt`, limite de tentativas e cookie `HttpOnly`
